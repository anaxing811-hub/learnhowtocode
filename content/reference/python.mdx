## Built-in types

| Type | Literal | Mutable? | Notes |
| --- | --- | --- | --- |
| `int` | `42` | — | Arbitrary precision; never overflows |
| `float` | `3.14` | — | 64-bit; `0.1 + 0.2 != 0.3` |
| `str` | `"text"` | no | Unicode |
| `bool` | `True` | — | A subclass of `int` |
| `list` | `[1, 2]` | yes | Ordered, indexable |
| `tuple` | `(1, 2)` | no | Hashable, so usable as a dict key |
| `dict` | `{"a": 1}` | yes | Keeps insertion order |
| `set` | `{1, 2}` | yes | Unique, unordered, O(1) membership |
| `None` | `None` | — | The absence of a value |

## Operators

```python
7 / 2       # 3.5   true division, always a float
7 // 2      # 3     floor division (rounds toward -inf: -7 // 2 == -4)
7 % 2       # 1     remainder
2 ** 10     # 1024  exponent
7 == 7.0    # True  value comparison
a is b      #       identity — only use for None, True, False
x in items  #       membership
```

## Built-in functions worth knowing

| Call | Does |
| --- | --- |
| `len(x)` | Length |
| `range(start, stop, step)` | Lazy sequence; `stop` is exclusive |
| `enumerate(x, start=0)` | Yields `(index, value)` |
| `zip(a, b)` | Yields tuples, stopping at the shorter |
| `sorted(x, key=…, reverse=…)` | New sorted list |
| `reversed(x)` | Lazy reverse iterator |
| `sum` / `min` / `max` | `min`/`max` take `key=` and `default=` |
| `any(x)` / `all(x)` | Short-circuiting truth tests |
| `map(f, x)` / `filter(f, x)` | Lazy; a comprehension is usually clearer |
| `abs` / `round(x, n)` / `divmod(a, b)` | `divmod` returns `(quotient, remainder)` |
| `isinstance(x, T)` | Type test that respects inheritance |
| `type(x)` | The exact type |

## Strings

```python
s = "Hello, World"

s.lower()          s.upper()        s.title()       s.strip()
s.split(",")       " ".join(words)  s.replace("l", "L")
s.startswith("He") s.endswith("ld") s.find("World")   # -1 if absent
s.index("World")                                      # raises if absent
s.count("l")       s.zfill(8)       s.center(20, "-")
s.isdigit()        s.isalpha()      s.isspace()

f"{value:.2f}"     # two decimals
f"{value:>10}"     # right-align in 10 columns
f"{value:,}"       # thousands separators
f"{value:.1%}"     # as a percentage
f"{value=}"        # "value=42" — very handy when debugging
```

Strings are immutable: every method above returns a new string.

## Lists

```python
items.append(x)          items.extend(other)      items.insert(i, x)
items.pop()              items.pop(0)             items.remove(x)
items.index(x)           items.count(x)           items.clear()
items.sort(key=…, reverse=…)      # in place, returns None
items.reverse()                   # in place
sorted(items)                     # returns a new list

items[start:stop:step]   items[::-1]              items[:]   # shallow copy

[f(x) for x in items if cond]              # comprehension
{k: v for k, v in pairs}                   # dict comprehension
{x for x in items}                         # set comprehension
(x for x in items)                         # generator — lazy, no list built
```

## Files and exceptions

```python
with open("data.txt") as f:        # closes automatically, even on an exception
    for line in f:
        print(line.rstrip())

with open("out.txt", "w") as f:
    f.write("hello\n")

try:
    value = int(text)
except ValueError as err:
    print("not a number:", err)
except (KeyError, IndexError):
    pass
else:
    print("no exception was raised")
finally:
    print("always runs")
```

Catch the narrowest exception you can. A bare `except:` swallows `KeyboardInterrupt`
along with your bug.

## NumPy

```python
import numpy as np

np.array([1, 2, 3])          np.zeros((2, 3))       np.ones(5)
np.arange(0, 10, 2)          np.linspace(0, 1, 5)   np.eye(3)
rng = np.random.default_rng(seed=0);  rng.normal(size=10)

a.shape    a.dtype    a.ndim    a.size
a.reshape(3, 4)       a.T       a.flatten()        a.astype(float)

a + b   a * b   a @ b          # elementwise, elementwise, matrix product
a.sum(axis=0)   a.mean(axis=1) a.std()   a.min()   a.max()
a.argmin()      a.argmax()     np.argsort(a)
a[a > 5]        np.where(cond, x, y)     np.clip(a, lo, hi)
np.concatenate([a, b])         np.stack([a, b])    np.unique(a)
```

`axis=0` collapses rows (one result per column); `axis=1` collapses columns.
The axis you name disappears.

Slices are **views** that share memory. Use `.copy()` when you need independence.

## pandas

```python
import pandas as pd

df = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
pd.read_csv("file.csv")        df.to_csv("out.csv", index=False)

df.head()   df.tail()   df.shape   df.info()   df.describe()   df.dtypes

df["col"]                      # a Series
df[["a", "b"]]                 # a DataFrame
df.loc[row_label, col_label]   # label-based
df.iloc[0, 1]                  # position-based
df[df["a"] > 1]                # boolean mask
df[(df["a"] > 1) & (df["b"] < 5)]     # note & and the brackets

df["new"] = df["a"] * 2
df.assign(new=lambda d: d["a"] * 2)
df.drop(columns=["a"])         df.rename(columns={"a": "alpha"})
df.sort_values("a", ascending=False)
df.groupby("key")["value"].agg(["count", "mean", "sum"])
df.groupby("key")["value"].transform("sum")     # aligned to original rows
df.merge(other, on="id", how="left")
df.pivot_table(index="a", columns="b", values="c", aggfunc="mean")

df.isna().sum()   df.dropna()   df.fillna(0)   df.duplicated()
```

<Callout type="gotcha" title="and / or do not work on Series">
Use `&`, `|` and `~`, and bracket every comparison. `df[df.a > 1 and df.b < 5]`
raises an ambiguous-truth-value error; `df[(df.a > 1) & (df.b < 5)]` works.
</Callout>

## Matplotlib

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, label="series")
ax.scatter(x, y, s=20, alpha=0.6)

```

Prefer the `fig, ax = plt.subplots()` form over the bare `plt.plot()` form —
it scales to multiple panels without rewriting.

## scikit-learn

Every estimator has the same shape: `fit`, then `predict` or `transform`.

```python
from sklearn.model_selection import train_test_split, cross_val_score, GridSearchCV
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.pipeline import make_pipeline
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y
)

model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
model.fit(X_train, y_train)
model.predict(X_test)
model.predict_proba(X_test)
model.score(X_test, y_test)

cross_val_score(model, X, y, cv=5)
GridSearchCV(model, {"logisticregression__C": [0.1, 1, 10]}, cv=5).fit(X, y)
```

### Choosing an estimator

| Task | Reach for |
| --- | --- |
| Classification, tabular | `RandomForestClassifier`, `HistGradientBoostingClassifier` |
| Classification, interpretable | `LogisticRegression`, `DecisionTreeClassifier` |
| Regression, tabular | `RandomForestRegressor`, `Ridge` |
| Clustering | `KMeans`, `DBSCAN` |
| Dimensionality reduction | `PCA` |

### Metrics

| Metric | Answers |
| --- | --- |
| `accuracy_score` | Fraction correct. Misleading on imbalanced classes |
| `precision_score` | Of those predicted positive, how many were |
| `recall_score` | Of the actual positives, how many were caught |
| `f1_score` | Harmonic mean of the two |
| `roc_auc_score` | Ranking quality, threshold-independent |
| `confusion_matrix` | Which classes get confused with which |
| `mean_absolute_error` | Regression error in the target's own units |

<Callout type="warning" title="Scale inside the pipeline, not before">
Fitting a `StandardScaler` on the whole dataset before splitting leaks test-set
statistics into training and inflates every score you report. Putting it in a
`Pipeline` means it is fitted per fold, which is what you want.
</Callout>

## Running Python locally

```bash
python3 -m venv .venv
source .venv/bin/activate           # Windows: .venv\Scripts\activate
pip install numpy pandas matplotlib scikit-learn
```
