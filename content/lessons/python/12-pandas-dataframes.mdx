A `DataFrame` is a table: named columns, each one a NumPy array, sharing a common index. It is the format almost all data arrives in.

```python run title="dataframe.py"
import pandas as pd

df = pd.DataFrame({
    "name":    ["Ada", "Alan", "Grace", "Edsger", "Barbara"],
    "field":   ["maths", "logic", "compilers", "algorithms", "compilers"],
    "born":    [1815, 1912, 1906, 1930, 1926],
    "papers":  [1, 27, 42, 88, 19],
})

print(df)
print()
print(df.dtypes)
print()
print(df.describe())
```

`describe()` is the first thing to run on any new table — it tells you the shape of the numbers and, by what is missing, where you have holes.

## Selecting

```python run title="selecting.py"
import pandas as pd

df = pd.DataFrame({
    "name":   ["Ada", "Alan", "Grace", "Edsger", "Barbara"],
    "field":  ["maths", "logic", "compilers", "algorithms", "compilers"],
    "born":   [1815, 1912, 1906, 1930, 1926],
    "papers": [1, 27, 42, 88, 19],
})

print(df["name"])                       # one column, as a Series
print()
print(df[["name", "papers"]])           # several columns, as a DataFrame
print()
print(df.loc[2])                        # one row by label
print()
print(df.loc[1:3, ["name", "born"]])    # rows and columns together
```

Note that `df["name"]` gives a **Series** (a single labelled column) while `df[["name"]]` gives a one-column DataFrame. The double brackets are a list of column names, not special syntax.

## Filtering with masks

```python run title="filtering.py"
import pandas as pd

df = pd.DataFrame({
    "name":   ["Ada", "Alan", "Grace", "Edsger", "Barbara"],
    "field":  ["maths", "logic", "compilers", "algorithms", "compilers"],
    "born":   [1815, 1912, 1906, 1930, 1926],
    "papers": [1, 27, 42, 88, 19],
})

modern = df["born"] > 1900
print(modern)
print()
print(df[modern])
print()
print(df[(df["born"] > 1900) & (df["papers"] > 20)])
print()
print(df[df["field"].isin(["compilers", "logic"])])
```

<Callout type="gotcha" title="Use & and |, and parenthesise">
Inside a mask you must write `&` and `|`, not `and` and `or` — the Python keywords cannot be overloaded for element-wise use. And because `&` binds more tightly than `>`, every comparison needs its own brackets. Forgetting them produces a confusing error about ambiguous truth values.
</Callout>

## Adding and transforming columns

```python run title="columns.py"
import pandas as pd

df = pd.DataFrame({
    "name":   ["Ada", "Alan", "Grace", "Edsger", "Barbara"],
    "born":   [1815, 1912, 1906, 1930, 1926],
    "papers": [1, 27, 42, 88, 19],
})

df["century"] = (df["born"] // 100) + 1
df["prolific"] = df["papers"] >= 25
df["initial"] = df["name"].str[0]

print(df)
print()
print(df.sort_values("papers", ascending=False).head(3))
```

The `.str` accessor applies string operations down a whole column. There is a `.dt` accessor for dates that works the same way.

## Grouping — the reason pandas exists

```python run title="groupby.py"
import pandas as pd

df = pd.DataFrame({
    "field":  ["maths", "logic", "compilers", "algorithms", "compilers", "logic"],
    "name":   ["Ada", "Alan", "Grace", "Edsger", "Barbara", "Kurt"],
    "papers": [1, 27, 42, 88, 19, 33],
})

print(df.groupby("field")["papers"].sum())
print()
print(df.groupby("field")["papers"].agg(["count", "mean", "max"]))
print()
print(df.groupby("field").size().sort_values(ascending=False))
```

*Split, apply, combine*: split the rows into groups by some key, apply an aggregation to each group, combine the answers into a new table. Almost every question you have about tabular data is a `groupby` in disguise.

## Missing data

```python run title="missing.py"
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "sensor": ["a", "b", "c", "d"],
    "reading": [1.5, np.nan, 3.2, np.nan],
})

print(df)
print()
print("missing per column:")
print(df.isna().sum())
print()
print("dropped:", df.dropna().shape)
print(df.fillna(df["reading"].mean()))
```

Real data has holes. `NaN` propagates through arithmetic — a sum that touches one `NaN` is `NaN` — so decide explicitly whether to drop those rows or fill them, and record which you chose.

<KeyPoints>
- `df["col"]` is a Series; `df[["col"]]` is a DataFrame.
- Boolean masks filter rows. Use `&` / `|` and bracket every comparison.
- `groupby` is split–apply–combine, and answers most questions about a table.
- `transform` returns a group-wise result aligned to the original rows; `agg` collapses to one row per group.
</KeyPoints>
