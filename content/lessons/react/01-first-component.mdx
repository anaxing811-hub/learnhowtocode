A React component is a function whose name starts with a capital letter and which returns something to draw. That is the whole definition.

```jsx run title="Hello.jsx"
export default function App() {
  return <h1>Hello, world!</h1>;
}
```

## JSX is not HTML

That `<h1>` is not a string and not HTML. It is **JSX**, and a build step turns it into a function call. These two are identical:

```jsx title="the same thing, twice"
const a = <h1 className="title">Hello</h1>;

const b = React.createElement("h1", { className: "title" }, "Hello");
```

Understanding that JSX is *just function calls returning objects* explains its rules:

- `class` becomes `className`, because `class` is a reserved word in JavaScript.
- `for` becomes `htmlFor`, for the same reason.
- Attributes are camelCase: `onclick` is `onClick`, `tabindex` is `tabIndex`.
- Every tag must close. `<br>` is invalid; write `<br />`.
- A component must return **one** root element, because a function returns one value.

```jsx run title="OneRoot.jsx"
export default function App() {
  return (
    <>
      <h2>Two elements</h2>
      <p>wrapped in a fragment, so nothing extra ends up in the DOM.</p>
    </>
  );
}
```

`<>...</>` is a **fragment** — a wrapper that groups children without producing a real element.

## Braces let JavaScript in

```jsx run title="Expressions.jsx"
export default function App() {
  const name = "Ada";
  const year = 1843;
  const skills = ["maths", "logic", "engines"];

  return (
    <div>
      <h2>{name}</h2>
      <p>Published in {year}, which was {2026 - year} years ago.</p>
      <p>Uppercase: {name.toUpperCase()}</p>
      <ul>
        {skills.map((skill) => (
          <li key={skill}>{skill}</li>
        ))}
      </ul>
    </div>
  );
}
```

Anything inside `{}` is a JavaScript **expression** — something that produces a value. `{2026 - year}` works; `{if (x) {...}}` does not, because `if` is a statement. When you need a condition inside markup, use the ternary or `&&`:

```jsx run title="Conditionals.jsx"
export default function App() {
  const temperature = 31;
  const alerts = [];

  return (
    <div>
      <p>It is {temperature > 30 ? "hot" : "not hot"} today.</p>
      {temperature > 30 && <strong>Stay hydrated.</strong>}
      {alerts.length > 0 && <p>You have alerts.</p>}
      <p>Alerts: {alerts.length}</p>
    </div>
  );
}
```

<Callout type="gotcha" title="Watch && with numbers">
`{alerts.length && <p>…</p>}` renders a bare `0` when the array is empty, because `0` is falsy but still a renderable value. Compare explicitly — `alerts.length > 0 && …` — and the problem disappears.
</Callout>

## Components use other components

```jsx run title="Composition.jsx"
function Badge({ label }) {
  return (
    <span style={{
      background: "#0f766e",
      color: "white",
      padding: "2px 8px",
      borderRadius: 999,
      fontSize: 12,
      marginRight: 6,
    }}>
      {label}
    </span>
  );
}

function Profile({ name, tags }) {
  return (
    <div style={{ border: "1px solid #ddd", borderRadius: 8, padding: 12 }}>
      <h3 style={{ margin: "0 0 6px" }}>{name}</h3>
      {tags.map((tag) => <Badge key={tag} label={tag} />)}
    </div>
  );
}

export default function App() {
  return (
    <div style={{ display: "grid", gap: 10 }}>
      <Profile name="Ada Lovelace" tags={["maths", "engines"]} />
      <Profile name="Grace Hopper" tags={["compilers", "navy"]} />
    </div>
  );
}
```

Two things to notice. The capital letter is load-bearing: `<Badge />` renders your component, while `<badge />` would emit a literal HTML tag React does not recognise. And `style` takes an object, not a string — hence the double braces `{{ }}`: the outer pair enters JavaScript, the inner pair is the object.

<KeyPoints>
- A component is a capitalised function returning JSX; the capital is what makes it a component.
- JSX compiles to `React.createElement` calls, which explains `className`, camelCase props and self-closing tags.
- `{}` embeds an expression, never a statement.
- Return one root; use `<>…</>` when you do not want a real wrapper element.
</KeyPoints>
